# Status and evidence model

| Status | Meaning |
|---|---|
| planned | Intended, not implemented |
| bootstrap | Initial specification or repository structure exists |
| experimental | Prototype exists; limitations remain |
| active | Maintained implementation with current evidence |
| maintenance | Primarily fixes and compatibility work |
| archived | No longer actively maintained |
| unverified | Claim has not been independently checked |

Attach a source URL and retrieval date to verifiable claims. State exact version, commit, configuration, and test scope. Separate observed behavior, maintainer assertion, inference, and user report. A passing test proves only the tested cases. Missing evidence is unknown, not failure or success.
