# LoLz Mesh Atlas

**NO GATEKEEPERS. GIVE THEM THE TOOLS.**

A public, forkable catalogue of LoLz projects, independently operated nodes, published capabilities, compatibility claims, releases, and contribution opportunities.

## Purpose
The Atlas is a discovery index—not a runtime coordinator, global trust authority, required hosted service, or proof that a listed project is secure or production-ready. Each project remains authoritative for its own code and releases.

## Principles
- Forkable and independently hostable; direct repository access remains possible if this index disappears.
- Public records only. Never publish private Think Tank material, credentials, or private operational records.
- Distinguish verified, experimental, planned, and unverified claims.
- Link evidence: releases, tests, schemas, and dated documentation.
- No global root of trust or mandatory LoLz infrastructure.

## Repository map
- catalogue/projects.yaml — initial public project catalogue.
- schemas/project-manifest.schema.json — manifest contract.
- docs/status-model.md — evidence and maturity vocabulary.
- docs/federation.md — independent-index model.
- CONTRIBUTING.md and SECURITY.md — project policies.

## Status
BOOTSTRAP. The catalogue and schema are initial scaffolding. Automated federation, synchronization, and validation are not yet implemented.
